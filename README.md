# Logging with html in Pythonn

html form to fetch user input
log the results with flask
handle errors and make a new log.txt file

---

## How it works

```
git clone https://github.com/gutiluis/form-html-with-log-fetch.git
cd form-html-with-log-fetch
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 listen_to_request_and_respond_with_flask.py
```
